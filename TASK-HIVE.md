# Task Hive: we pay people for reality, not for code

Task Hive is how blackcode pays people outside the company for small, well-defined jobs.

**The one rule:** our AI agents write the code, the design and the documentation. Paying people to write code would be throwing money away. **People are paid to try our software on real machines in the real world**: install it on a real device, unpack it, run it, and **prove** it works, or show exactly where it breaks.

Every bounty answers one question:

> **Does this actually work out there, on a machine we don't own?**

## What a Task Hive job looks like

- **Install and connect tests**, per operating system and per antivirus: for example a real Windows 10/11 PC with Norton, McAfee or Kaspersky switched on, a Mac, or a Linux laptop.
- **Real-phone flows**: Android and iPhone, using the app or the dashboard the way a real user would (microphone, notifications, voice mode).
- **Field setups**: a small office, a shop, a home network, a slow or unusual connection.
- **Physical hardware checks**: a specific device, port, printer, card reader or USB stick, tried for real.

## The proof (required, or the job is not done)

1. **A full screen video** of the whole run, from download to the end, uncut.
2. **A numbered list of observations**: every failure, prompt, warning or confusing step, with the exact text or a screenshot.
3. **The machine's facts**: OS and version, antivirus and version, account type, language.
4. Where the task asks for it, **a live connection** to a test fleet that *you* create (never ours), or **a log file** from that machine.

**Failures count.** A clear report of what broke is exactly what we pay for.

## What never qualifies

- Code, pull requests or patches
- Documentation or translations
- Design, mock-ups or ideas

## How tasks are chosen and paid

- **Every task is defined or approved by Andrea Edelman** (blackcode SA). Agents never invent tasks for people.
- Each task is published as an issue with its price. **The first complete report that passes our review wins.** Commenting does not reserve a task.
- **Payment:** after Andrea's review and a 1-2 day window, by Payoneer or PaySend. Never automatic, never a bank transfer to countries where that is unsafe for the recipient.
- **Budget:** each pilot has a fixed total budget. No task is posted beyond it.
- **Safety:** use your own devices only. Never share real client or personal data in your proof.
